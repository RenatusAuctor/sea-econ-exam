# 동남아시아 경제론 기말대책

기말고사 대비 자가 채점형 문제집 + 요약 노트 (2026년도 자료판). 탭 3개로 구성.

| 탭 | 내용 | 근거 |
| --- | --- | --- |
| 모의시험 | 40문 / 50점. 2025년도 기출과 같은 형식·배점 | 배포 레쥬메 216C~228C |
| 보충문제 | 60문 / 60점. 모의시험이 다루지 않는 범위 | 수업 중 형광펜 표시 슬라이드 (제16~25회) |
| 포인트 노트 | 제16~28회 회차별 요약 (표·함정 정리) | 위 둘의 합본 |

- 바로 풀기: https://renatusauctor.github.io/sea-econ-exam/
- 파일: `index.html` (단일 파일, 외부 의존성 없음 — 다운로드해서 오프라인으로도 열림)
